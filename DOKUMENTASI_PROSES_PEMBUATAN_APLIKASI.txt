                              1. OVERVIEW PROYEK
=============================================================================

Nama Aplikasi: RAVAZKA E-Commerce System
Jenis: Aplikasi Web E-Commerce untuk Seragam Sekolah
Framework: Laravel 12.x
Database: MySQL
Frontend: Blade Templates + Bootstrap 5 + TailwindCSS
Bahasa: PHP 8.2+

Tujuan Aplikasi:
- Mengelola inventaris seragam sekolah
- Memfasilitasi pemesanan online untuk pelanggan
- Menyediakan dashboard admin untuk manajemen pesanan
- Mengotomatisasi proses bisnis dari katalog hingga pengiriman

Fitur Utama:
✓ Manajemen Inventaris (CRUD)
✓ Katalog Produk dengan Filter
✓ Keranjang Belanja Persisten
✓ Sistem Pemesanan & Checkout
✓ Manajemen Pesanan Admin
✓ Laporan Penjualan & Inventaris
✓ Autentikasi Multi-Role (Admin/Customer)
✓ Upload Bukti Pembayaran
✓ Tracking Status Pesanan

2.1 PERSIAPAN ENVIRONMENT

2.2 INSTALASI LARAVEL
---------------------
Langkah-langkah:
1. Membuat proyek Laravel baru:
   composer create-project laravel/laravel kerja-praktik

2. Konfigurasi file .env:
   APP_NAME="RAVAZKA E-Commerce"
   APP_ENV=local
   APP_DEBUG=true
   APP_URL=http://localhost/kerja-praktik
   
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=kerja_praktik
   DB_USERNAME=root
   DB_PASSWORD=

3. Generate Application Key:
   php artisan key:generate

2.3 SETUP DATABASE
------------------
1. Membuat database MySQL:
   CREATE DATABASE kerja_praktik;

2. Test koneksi database:
   php artisan tinker
   DB::connection()->getPdo();

2.4 INSTALASI DEPENDENCIES

                      3. PERENCANAAN & DESAIN ARSITEKTUR
=============================================================================

3.1 ARSITEKTUR APLIKASI
-----------------------
Pola Arsitektur: MVC (Model-View-Controller)
Structure Pattern: Repository Pattern (untuk beberapa komponen)
Design Pattern: Observer Pattern (untuk event handling)

Struktur Direktori:
app/
├── Http/Controllers/
│   ├── Admin/          # Controller untuk admin
│   ├── Customer/       # Controller untuk customer
│   └── Auth/          # Controller autentikasi
├── Models/            # Eloquent Models
├── Observers/         # Event Observers
├── Services/          # Business Logic Services
└── Helpers/           # Helper Functions

3.2 DATABASE DESIGN
-------------------
Tabel Utama:
1. users (Pengguna sistem)
2. products (Data produk)
3. inventories (Data inventaris)
4. orders (Data pesanan)
5. order_items (Item dalam pesanan)
6. carts (Keranjang belanja)
7. testimonials (Testimoni pelanggan)

Relasi Database:
- User hasMany Orders
- Product belongsTo Inventory
- Order hasMany OrderItems
- OrderItem belongsTo Product
- Cart belongsTo User (optional)

3.3 USER FLOW DESIGN
--------------------
Customer Flow:
Beranda → Katalog → Detail Produk → Keranjang → Checkout → Pembayaran → Tracking

Admin Flow:
Login → Dashboard → Manajemen (Inventaris/Pesanan/Laporan) → Logout

3.4 UI/UX DESIGN PRINCIPLES
---------------------------
- Responsive Design (Mobile-First)
- Clean & Minimalist Interface
- Consistent Color Scheme
- Intuitive Navigation
- Fast Loading Performance
- Accessibility Compliance

=============================================================================
                            9. TANTANGAN & SOLUSI
=============================================================================

9.1 TANTANGAN TEKNIS
--------------------

Tantangan 1: Database Foreign Key Constraints
Masalah: Error saat seeding data karena foreign key constraint
Solusi: 
- Disable foreign key checks sementara
- Reorder seeding sequence
- Implement proper data relationships

Tantangan 2: Session Management untuk Cart
Masalah: Cart data hilang saat user logout/login
Solusi:
- Implement persistent cart dengan database
- Merge session cart dengan user cart
- Add cart migration logic

Tantangan 3: Image Upload & Storage
Masalah: File upload tidak berfungsi di production
Solusi:
- Configure proper storage permissions
- Implement symbolic links
- Add file validation

Tantangan 4: Performance dengan Large Dataset
Masalah: Slow query saat data produk banyak
Solusi:
- Add database indexes
- Implement pagination
- Use eager loading
- Add query optimization

9.2 TANTANGAN BISNIS
--------------------

Tantangan 1: User Experience
Masalah: Interface terlalu kompleks untuk user
Solusi:
- Simplify navigation
- Add user guidance
- Implement responsive design
- User testing & feedback

Tantangan 2: Inventory Synchronization
Masalah: Stock tidak sinkron antara produk dan inventaris
Solusi:
- Implement Observer pattern
- Add real-time stock updates
- Create stock validation
- Add stock history tracking

9.3 SOLUSI IMPLEMENTASI
-----------------------

Code Example - Foreign Key Fix:
```php
// InventoryTableSeeder.php
DB::statement('SET FOREIGN_KEY_CHECKS=0;');
Inventory::truncate();
Product::truncate();
DB::statement('SET FOREIGN_KEY_CHECKS=1;');
```

Code Example - Observer Pattern:
```php
// ProductObserver.php
public function updated(Product $product)
{
    $product->updateInventoryStock();
}
```
